# 使用指南

1. 从Releases下载Windows x64包，解压并保留LICENSE、第三方说明和licenses目录。
2. 运行BootScanner.exe，先阅读底部风险提示；点击“查看免责声明”查看全文。
3. 选择有权分析的本地Boot目录，或拖入目录/在路径框输入后回车。
4. 左侧为文件明确提供的系统与硬件信息；右侧为可用符号或明确标注的从站过程数据；底部列出文件诊断。
5. 搜索支持名称、类型、方向和地址文字。悬停节点/单元格可查看来源提示。
6. 扫描中可点击“取消扫描”或按Esc；正在解析的单文件完成前可能不能立即取消。
7. 导出CSV时选择Boot以外目录。导出两张表：变量/过程数据和拓扑。分享前检查路径、变量名和客户信息。

## 工程名称与路径

XML明确记录的组态路径与PLC工程路径会原样展示，但两者不是同一种文件。符号文件名不证明PLC工程名。WSM字符串候选有来源偏移和“关联未验证”提示，仅说明在配置流中找到了相应记录形态，不保证文件存在、当前可访问或确实关联到指定PLC。

程序不会打开这些历史目标路径，也不会主动访问路径所指的网络位置。

## 常见状态

- 已解析：读到了当前支持的结构；可能仍为部分解析，请阅读细节。
- 已识别：格式或角色明确，但未必能读取工程内容。
- 已跳过：主动不处理的启动/保持文件等。
- 暂不可用：缺少可选信息或当前能力不支持，不等于文件损坏。
- 未知类型：未读取内容；不要按解析失败理解。
- 失败：已尝试读取的文件出现格式、权限或读取错误。

本项目不包含演示Boot目录。请勿通过公开Issue上传现场工程或完整Boot文件。
