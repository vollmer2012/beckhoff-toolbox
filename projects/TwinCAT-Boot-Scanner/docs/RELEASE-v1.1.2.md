# v1.1.2-preview.1 · Public Preview · Windows x64

Boot Scanner（Boot 查看器）的首个公开预览版本。独立第三方离线工具，非Beckhoff官方产品；结果仅供参考。

## 本版内容

- 使用Windows Structured Storage系统接口只读读取TC2复合文档，不依赖或分发OpenMcdf。
- 读取支持的XML、TMC/TMI、TPY及部分TSM从站描述，展示有依据的系统、设备和符号/过程数据。
- 显示明确XML工程名和历史文件路径；WSM字符串候选单独标记关联未验证。
- 后台扫描、取消、CSV来源、只读导出保护和资源限制。
- 界面固定风险提示与完整免责声明入口。
- MIT许可、运行时第三方声明、技术栈/架构/使用/支持边界文档。
- 公开测试20项通过，Windows Release构建通过。

## 使用

下载Windows x64 ZIP，解压后运行BootScanner.exe。保留LICENSE、第三方许可和免责声明文件。使用者不需要安装.NET或TwinCAT。

## 重要限制

完整WSM工程与映射尚未解码；从站过程数据不是完整PLC符号表；不恢复PLC源码，不在线访问控制器，不替代官方工程工具或现场安全核验。
