# 支持范围与已知限制

- Windows 10/11 x64桌面应用；TSM复合文档读取依赖Windows系统API。
- TC2通过固定硬件文件、启动文件和路径等证据识别；TcBootProject名称本身不证明TC3。
- 证据冲突不等于项目损坏、目录混放或已经验证的版本归属。
- TC3工程XML与TC2/TC3运行时ProjectInfo的可读结构分别处理。
- 未解码WSM主工程，未实现完整系统管理器硬件、PLC和Mappings恢复。
- SlaveDeviceInfo中的Producing/Consuming从站过程数据不是完整PLC符号表，其Id/BitSize不是推断的PLC地址。
- 没有TPY/TMC/TMI时不能保证有可展示PLC符号；没有显式Link时不猜映射。
- 数字Type不当成订货号；不编造工控机型号和物理布线。
- WSM路径候选当前仅支持有单字节长度证据、最多254字节的ASCII盘符绝对路径，且须以.tpy/.pro/.plcproj完整后缀结束。不支持UNC/Unicode/长字符串等未知记录形式。
- XML任务周期按现有100ns换算；Context暂按ns，显示原值和单位待核提示。
- 不反编译程序体，不恢复PLC源码，不绕过授权，不连接控制器。
- 文件/目录链接会被跳过。扫描不是故障诊断、现场验收或安全认证工具。
- XML64MiB/256层、TSM256MiB、受支持XML流8MiB、WSM候选流16MiB是资源上限，超出会跳过或给出诊断。
- 单文件内解析不可瞬时中断；导出过程不会写回选定Boot。
- 当前不声称支持所有版本、所有厂商扩展或所有压缩形态。

本公开仓库只带源码和生成最小输入的单元测试，不带Boot项目例子、工程文件、测试夹具资产或客户样本。
