## 版本管理

项目目录固定为 `projects/Beckhoff-Finder/`，项目名称为 **Beckhoff Finder**。后续版本在同一项目目录中更新说明，通过独立 Release 和标签发布运行版；旧版本的附件、校验值及下载入口保留，便于回溯。

Release 标签使用项目名前缀，例如现有的 `beckhoff-finder-v1.01`；后续版本可使用 `beckhoff-finder-v1.02`，与同仓库的其他工具区分。每次发布同步更新当前版本、对应文件记录、校验文件和版本记录。
