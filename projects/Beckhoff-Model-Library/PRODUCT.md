# 倍福型号资料库

面向经常查阅倍福选型资料的工程人员。主要任务：按订货号或中文关键词找规格简介，按主机找配套，从结论回到官方来源并查看资料差异。

数据保存在用户的 GitHub 私有仓库；当前没有远程地址。先在本地完成静态查询及 Markdown。首批依据官方产品选型页及 Infosys，后续持续扩充。

已确认功能：完整/部分型号搜索、中文关键词、多条件筛选、详情规格、配套条件、来源及历史记录。内容很多时优先保持结果易扫描；不得通过型号规律猜配套。

实施选择：零依赖静态 HTML/CSS/JavaScript，JSON 单一数据源，Node 构建与测试。桌面工程查阅优先，兼容手机。无账号系统，私有部署后续由托管层提供。

待确定：GitHub 私有仓库地址、正式托管平台、后续各产品线收录优先级。
