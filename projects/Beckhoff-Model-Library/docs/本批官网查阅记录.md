# 本批官网查阅记录

查阅日期：2026-11-19。以官方具体选型页为主要依据，Infosys 附件章节补充历史型谱。没有使用第三方经销商的参数作为本批数据依据。

## 查阅要点

- CX5130：技术规格、订货后缀与系统组合、CFast 最小容量、可选接口、附件、供货阶段及推荐替代。
- CX7000：CPU、内存、集成 I/O、TwinCAT/RTOS、microSD 的订购与附件区分；没有将多功能 I/O 的所有复用能力同时当成独立通道。
- CX9020：双 microSD 槽、内部交换机、WEC7 配置、无系统配置的 Linux 限制、UPS 与卡选项、推荐替代。
- C6015-0040：参数表与三组必选配置（CPU/内存、SSD、安装方式），以及独立于配置上限的具体订货项。
- C6030-0080：标准规格列与升级选项列；没有把最高内存或温度范围当作标准配置。
- 存储：microSD 的扩容/备件号、公告型号；CompactFlash 服务阶段与格式化服务；CFast 的系统限制；部分 SATA/M.2 SSD。
- 操作系统：BSD 与 RT Linux 的具体平台等级许可证；Windows 11 的 CPU 档位、语言、64 位、磁盘容量及 TwinCAT build 要求；含 x 的型号模式明确不可直接下单。
- I/O：EK1100、EL1008、EL2008、EL3062、EL4002 的简介和关键规格，不按系列名称自动生成未查型号。

## 差异与限制

1. CFast 20 GB 的系统限制在产品页比 CX2000 附件行更详细，记作资料差异。
2. microSD 手册所列容量和当前英文产品页列项不同。没有足够依据认定手册条目已停产；保留手册记录。
3. EK1100 同页简介和技术表的数量数字不同，可能是整体系统与端子计数口径，标为待核实冲突。
4. CX5230 等页面部分读取失败，未用第三方结果或型号规律填充。待查列表已登记。
5. 通用附件索引动态加载，静态内容不足以证明目录完整，故转查具体型号选型页。
6. 官网普通 HTTP 下载受到 403 限制，浏览检索仍能读取对应官方内容；本批没有声称已归档 HTML/PDF 原文件。
