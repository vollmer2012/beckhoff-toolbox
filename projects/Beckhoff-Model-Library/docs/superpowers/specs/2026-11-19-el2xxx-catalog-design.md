# EL2xxx 资料批次设计

## 目的

在既有倍福型号资料库中补齐当前英文官网 EL/ED2xxx 总览明确列出的 EL2xxx 型号，供工程人员按订货号、输出类型、电压、电流、诊断、安全及脉冲/PWM 等关键词检索。

## 范围与边界

- 仅收录总览页明确链接的 EL2xxx 具体型号，并逐条绑定对应官网产品页。
- 不将 ED、ES、ELM、EM、ELX 型号混入本批；同页出现的 ES 订货行只作为页面结构背景，不创建记录。
- 官网参数是资料整理，不是安全认证、实机兼容性或采购可得性保证。
- 产品状态按具体页面查阅结果记录；`last time buy` 与 `regular delivery` 必须区分。
- 不按型号规律推断通道、电压、接线、输出类型或后缀含义。

## 方案

沿用现有单一数据源方案：官网总览确定批次边界，具体产品页提供参数和状态，`data/catalog.json` 保存结构化结果，构建器生成网页与 Markdown，测试验证覆盖和关键差异。备选的“只导入总览摘要”证据粒度不足；“直接收录整个 EL 全系列”批次过大且容易混淆产品族，因此不采用。

## 数据与文件

- `research/el2xxx-verified-fields-2026-11-19.json`：本次逐页提取记录。
- `data/catalog.json`：新增/修订产品、来源及更新时间。
- `tests/el2xxx-coverage.test.cjs`：覆盖、状态和关键规格回归。
- `scripts/build.mjs`：生成 `docs/EL2xxx收录清单.md` 并复制到 `dist/`。
- `docs/更新记录.md`、`docs/工作进度.md`、`README.md`：公开说明本批范围与限制。

## 风险

- 安全：TwinSAFE 参数不构成安全设计依据，接线与认证须回到相应安全手册。
- 资料：官网页面可能更新；保留查阅日期和页面原文值，不把查阅时间当发布日期。
- 网络安全：静态页面不连接 PLC、不开写接口，不改变现有 GitHub Pages 暴露面。
