## 查询入口

- 按订货号查：例如 CX1900-0124、CX2900-0026。
- 按类别查：存储介质 / 操作系统 / 主机硬件 / 附件 / 出厂选件。
- 按主机查配套：仅列出有明确官方来源的配套关系。
- 查历史：保留旧手册记载、当前网页记载及适用条件。

Markdown 版通过目录和浏览器查找阅读；独立网页版可增加型号搜索、类别筛选、主机筛选及详情展开。这里列的是页面内容示例，并非已经实现的网页功能。

## 正式资料库维护方式（建议）

- 结构化数据保存完整型号、分类、规格、适配条件及证据来源，生成此类 Markdown 页面。
- 同一型号允许多个来源；冲突针对具体属性和适用范围记录。
- 查阅日期与资料发布日期分开；未知字段明确留空或标“未核实”。
- 备件、随主机扩容选件、型号模式、完整订货号分别标识。
- 未找到、手册未列出、明确不支持，使用不同状态。
- 新旧资料差异经核对后再更新查询结论；历史证据继续保留。
- 当前预览不包含已经验证的具体主机硬件档案；正式版补充主机参数及配套关系。
