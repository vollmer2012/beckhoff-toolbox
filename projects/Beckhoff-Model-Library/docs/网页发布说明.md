# GitHub Pages 发布

源码位于公开仓库 `vollmer2012/beckhoff-toolbox` 的 `projects/Beckhoff-Model-Library/`。网页、数据和下载资料均为公开内容。

仓库根目录的 `.github/workflows/model-library-pages.yml` 负责测试、构建及部署，不修改其他项目。

## 首次启用

1. 打开仓库 Settings → Pages。
2. 在 Build and deployment 中将 Source 设为 GitHub Actions。
3. 在 Actions 中打开“型号资料库网页”，点击 Run workflow，选择 main。
4. 等待 build 和 deploy 均成功，从部署结果打开网址。成功前不要把预计地址当作已经可访问的网站。

预计网址：`https://vollmer2012.github.io/beckhoff-toolbox/`。最终以 Pages 设置页或部署结果为准。

## 后续修订

修改本项目的 `data/catalog.json`，保留官方来源、适用条件及冲突记录。运行 `npm test` 和 `npm run build`，提交源码与生成文件。推送 main 后工作流自动测试并更新网页；失败时查看 Actions 日志，不能仅凭提交成功认定网站更新成功。

本站只是资料检索预览版。反馈通过仓库 Issues，修改通过文件历史和提交记录追溯。不要上传客户工程、密码、令牌、个人网络诊断或无权公开的第三方全文资料。

仓库已有其他 Pages 网站时，应先合并发布目录和流程；本次检查仓库文件中没有其他 Pages 工作流。
